# 小鲸鲸陪伴 · dsh-pet-companion

给 [DeepSeek Harness](https://github.com/deepseek-ai) 桌面版 / 网页版做的**桌宠陪伴插件**，以及配套的本地工具与补丁脚本。

一个纯浏览器 UI 的 DSH 插件：左下角常驻一条**不惹眼的小胶囊**（只显示番茄倒计时），点一下展开完整面板。

> 桌宠形象与语音来自第三方插件（dsh-pet / dsh-xiaomi-tts），本仓库只包含我们自己写的插件、工具与补丁脚本。

## 一、插件：dsh-pet-companion

### 功能（v0.4）

| 标签 | 功能 | 花费 | 依赖 |
|---|---|---|---|
| 🍅 专注 | 三模式：**番茄钟**（25/45/60 预设 + 自定义专注/休息分钟）、**正计时**（自由计时，可记入统计）、**自定义倒计时**（任意分钟）；进度环 + 今日统计 + 结束提示音 + 桌宠冒泡 | **0 token** | 无（有桌宠时联动冒泡） |
| 🗒 待办 | 本地待办清单：勾选完成、设为当前专注任务、清理已完成 | **0 token** | 无 |
| 💧 提醒 | 喝水 / 久坐本地定时提醒（间隔可调，可试一下） | **0 token** | 无 |
| 📚 讲解 | 输入主题 → 定义 + 要点 + 比喻 + 自测题；历史与复制 | ≈1 次模型调用 | 桌宠在运行（借其聊天模型） |
| ✏️ 辅导 | 贴题目 → 考点 → 分步思路 → 答案 + 卡点提醒 | ≈1 次模型调用 | 桌宠在运行 |
| 🐟 桌宠 | 显示位置四选一（都显示 / 仅桌面 / 仅 DSH 页面 / 隐藏）+ 「DSH 最小化时自动隐藏桌宠」 | **0 token** | 桌宠在运行 |
| 🎮 游戏陪伴 | 开关先记住（后续接前台窗口检测） | — | 后续版本 |
| 🎤 语音聊天 | 开关先记住（后续接麦克风与语音识别） | — | 后续版本 |

- 面板形态：**完整 / 小胶囊（默认，最不惹眼）/ 小圆点**；`Alt+P` 快速隐藏/展开
- 设置 →「小鲸鲸陪伴」（插件页同款）里可独立开关每个功能、切面板形态、清零今日统计
- 所有数据存本地 `localStorage`，重启不丢；纯前端、无遥测、无外部请求（讲解/辅导只调本机桌宠接口）

### 安装

```bash
# 从 GitHub 安装（DSH 0.2.x）
dsh plugin --profile desktop add https://github.com/cshengyi023-collab/dsh-pet-companion
```

或本地路径：

```bash
dsh plugin --profile desktop add D:\path\to\dsh-pet-companion
```

装完重启 DSH，左下角出现小胶囊。

## 二、配套工具（tools/）

| 目录 | 说明 |
|---|---|
| `tools/桌宠控制台/` | Tkinter 小窗口：说话 / 动作 / **试音**（8 个预设音色 + 自定义音色设计预设，点谁听谁）/ 显示位置 / 读书入口。`桌宠控制台.cmd` 双击启动 |
| `tools/朗读台/` | 用桌宠音色读书 / 念讲义 / **朗读剪贴板**（`朗读剪贴板.cmd`）。长文按段合成、自动拼接 |
| `tools/陪伴服务/` | 本地定时陪伴：番茄钟 / 久坐 / 喝水 / 整点问候 → 桌宠气泡（0 token）。`陪伴服务.cmd` 启动、`开机自启.cmd` 登记开机启动 |

> 工具是给自己电脑写的：脚本里有作者本机的绝对路径（`C:\Users\...`）和运行时路径，**用之前按自己的环境改一下**。

## 三、补丁脚本（patches/）

对第三方插件的本地增强（**只改本地已安装文件**，插件升级后需重跑）：

| 目录 | 作用 |
|---|---|
| `patches/persona/` | 把桌宠人设改成「小鲸鲸」（小孩心性、会发脾气、爱吃白饭）；给语音插件加「小鲸鲸」音色设计预设（前后端两份清单 + 头像）；修非流式播报 |
| `patches/desktop-sound/` | 桌面宠物按压 Q 弹动画 + 小黄鸭音效 + 修复 hover 标签偏移 |
| `patches/key-reveal/` | 语音插件 API Key 输入框加「显示/隐藏」按钮 |
| `patches/voice-fix/` | 本地兜底语音、稳定音色组合、关闭自动朗读等修复 |
| `patches/balance-patch/` | 桌宠余额按「赠送+充值」合计显示 |
| `patches/plugin-icon/` | 用她的立绘合成插件图标 |
| `patches/petctl.py` | 桌宠命令行控制：state / say / whisper / chat / anim / display |
| `patches/ROADMAP-陪伴能力.md` | 陪伴能力路线图与已完成清单 |

> 这些脚本会修改 `node_modules` 里的第三方插件文件，**请自行确认许可与风险**；升级插件后补丁会丢失。

## 四、版本 / 标签

- `v0.4.3` — 桌宠显示选项加上数量说明：仅桌面（1 个）/ 仅界面（1 个）/ 两处都显示（2 个）/ 都隐藏（0 个），避免「怎么有两个」的误会
- `v0.4.2` — 修复桌面版（`dsh-app://` 页面）里桌宠接口全部调不通：改用同源相对路径（相对地址由宿主协议代理），桌宠显示/隐藏、讲解、辅导、提醒冒泡恢复正常
- `v0.4.1` — 修复：切换「待办 / 提醒 / 讲解 / 辅导 / 桌宠」标签时面板空白（渲染函数不支持文本子节点）；新增 jsdom 冒烟测试
- `v0.4.0` — 桌宠显示控制：显示位置四选一（都显示/仅桌面/仅页面/隐藏）+ DSH 最小化时自动隐藏，面板新增「🐟 桌宠」标签
- `v0.3.0` — 专注计时升级：番茄钟 + 正计时 + 自定义倒计时三模式；可自定义专注/休息分钟；结束记入统计
- `v0.2.0` — 陪伴面板 v0.2：进度环番茄钟、今日统计、待办便签、喝水/久坐提醒、讲解/辅导历史与复制、低调模式（小胶囊默认）

## 五、开发 / 测试

面板是手写 DOM 逻辑，仓库里带了一个 jsdom 冒烟测试（挂载面板 → 点开每个标签 → 切换三种专注模式）：

```bash
cd tests
npm i jsdom
node smoke.mjs
```

退出码非 0 表示有运行时错误。
