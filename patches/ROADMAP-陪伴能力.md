## 2. 音色方案（"复刻鲸鱼娘声音"）

优先用**原创音色设计**，不克隆真人声音（授权风险）：

1. **小米 MiMo 音色设计（推荐）**：插件自带「鲸鱼娘」预设描述（清甜灵动、懒懒的元气、表面傲娇内里温柔）。需要免费 API key：<https://platform.xiaomimimo.com/console/api-keys>（注册→创建 key→发给 DSH 或让 AI 写入配置）。生成即用，无需样本。
2. **豆包声音复刻（seed-icl-2.0）**：需要 ≥10s 的**本人授权样本**和火山引擎 key；适合"想要某个具体音色"的场景，不适合网上随便找的声音。
3. **浏览器本地语音（兜底）**：0 token、离线可用，音色一般（Windows 自带中文语音）。

> 结论：先用 1 打通，再用 3 兜底；2 只在有授权样本时用。

## 3. 麦克风聊天（MVP 设计）

- **开关**：「麦克风聊天」总开关（默认关，首次开启弹权限说明）；子开关：自动朗读回复、是否保留录音。
- **流程**：按住说话 → ASR → `POST /dsh-pet-7340/chat`（她的人设 + token 预算）→ 回复气泡 → TTS 播报。
- **ASR 选型**：优先**本地 Whisper（whisper.cpp）**（0 token、不上传）；云端 ASR 作为可选（差网络/低配机）。
- **花费提示**：每次对话 ≈ LLM 一次调用（短对话几百~几千 token），UI 显示"本次约 ¥x / N tokens"。
- **平台**：Windows 桌面优先（Electron `getUserMedia` + 本地 whisper 子进程），Web 端次之。

## 4. 陪玩游戏（设计）

- **感知层（便宜优先）**：前台窗口标题/进程名（本地，0 token）→ 判断"在玩什么/在哪个应用"。
- **表达层**：按频率（默认 5–10 分钟一次，静默优先）让小模型生成一句短评 → 气泡 + TTS；**游戏全屏时默认闭嘴**（可在开关里允许）。
- **可选进阶**：截图 → 视觉模型（贵，默认关，单独开关 + 日预算上限）。
- **隐私**：默认只读窗口标题，不截图、不上传；截图能力单独授权。

## 5. 自动看视频 / 陪看（设计）

- **开关**：「陪看模式」默认关，开启时明示"会抽帧并调用视觉模型，按分钟计费"。
- **流程**：检测播放器/浏览器视频窗口 → 每 N 秒抽 1 帧（可调）→ 视觉模型短描述 → 累积成"陪看笔记"，可随时让她说一句。
- **预算**：日 token 上限（如 20 万），达到即自动停；界面显示已用。
- **替代低成本版**：只读窗口标题/播放进度（0 token）+ 少量文字评论（LLM 便宜档）。

## 6. 多平台 / 多服务商

- **语音服务商**：现有 小米 MiMo / 豆包 / 浏览器本地；计划增加 OpenAI TTS、Edge-TTS（免 key 音质尚可）、本地 GPT-SoVITS（可完全自建音色，需显卡）。
- **运行平台**：DSH 桌面（已支持，透明窗）/ DSH Web overlay（已支持）/ 未来：手机端（仅网页 overlay，语音走浏览器）。
- **统一抽象**：所有能力走"开关 + 预算 + 花费估算"三件套，写进设置页。
